# Опись: окно постройки, ч. 1 — каркас и ратуша

Рабочая копия `war-of-tribes-ui`, пути от корня репозитория. Номера проблем сквозные: **A** = П1, **B** = П2, **C** = П3.

**Допущения для пикселей** (оценка по CSS, без замера): телефон 390×844, Telegram развёрнут (`expand`, не fullscreen), `--app-h` ≈ 740. Шторка `Sheet.tsx:6-7`: peek 62 % = 459 px, full 85 % = 629 px. Ручка `.sheet-grab` 44 px (`styles.css:343-351`). Нижняя навигация (z 12) лежит поверх шторки (z 10): 56 + safe-bottom 34 = 90 px. Видимая высота содержимого: **peek ≈ 325 px, full ≈ 495 px**. Текст 12 px при line-height 1.4 = 16.8 px на строку; ширина строки 366 px ≈ 56 знаков кириллицы.

## Сколько нажатий до «улучшить здание»
- **Из сцены:** тап по крыше → шторка (peek), кнопка «До N ур.» видна в шапке → тап. **2 нажатия**, без подтверждения. Слабое место — попасть по крыше: сама навигация признаёт, что «на 390 px пальцем по крыше не попасть» (`BottomNav.tsx:10`).
- **Через «Ратуша» внизу:** тап «🏛️ Ратуша» (вкладка «Стройка» ставится сама) → **прокрутка**: первая «Уровень N» на ≈450 px, ниже видимых 325 при peek → тап «Уровень N». **2 нажатия + 1…8 прокруток** (казармы — последние в порядке `BUILDINGS`). Если ратуша уже открыта на «Стройке», тап по навигации закроет её (+1).
- **Ратуша → строка → окно здания → «До N ур.»:** **3 нажатия** + прокрутка.
- **Достройка за алмазы из ратуши:** те же 2 нажатия + прокрутка, без подтверждения (A4).

## Сводка зоны
- **Счёт:** П1 — 5, П2 — 22, П3 — 19.
- **Шапка съедает экран.** Общий каркас (ручка, шапка 50 px, описание до 6 строк, плашка «за стеной», блок улучшения) занимает ≈190–300 px — 58–92 % видимого при peek. У дворов ряд «+» уходит под сгиб (A2), у ратуши список начинается почти за краем (A5).
- **Ратуша «Стройка» — самая длинная панель:** ≈2600–4200 px, 8–13 экранов при peek. Разделы перестраиваются по тому, хватает ли ресурсов, и строки ездят под пальцем.
- **Сроки в голых секундах** («~1274 с», «75000 с разъездов») в цене каждого улучшения и ступени дозора. Рядом та же стройка в очереди пишет «~21 м 14 с» (A1).
- **Разрушительные действия без подтверждения и с плохой подписью:** «♦ N» в 6 px от «Уровень N» тратит алмазы, голый «✕» отменяет стройку с потерей половины ресурсов (A3, A4).
- **Подписи разнобойные:** семь записей «уровень / улучшить», «Паёк» против «Рацион», две разные «мораль» на кнопке налога, два разных множителя у одного рабочего, «Строителей» с единицей скорости, «21 клеток» (B3, B9, B10, B6, B17, B18).
- **Текст объясняет, а не подписывает:** длинные описания и заметки (Статуя, ратуша, алмазы с «вебхуком», дружина, оборона) стоят выше действий. Подсказок по долгому нажатию нет, а пояснения в `title=` на телефоне не видны (B8).
- **Цели касания:** все кнопки зоны держат 44 px (`--tap`). Мелкий — только текст: подписи 10 px, метка 9 px (C19). Счётчик алмазов на вкладке — красное по красному (B14).
