# Опись: язык игры — термины, тон, длина, числа в тексте

Корпус: `texts/in-01…24.json` = 3790 строк игрока (strings.json без 17 строк dev и 89 строк служебных файлов:
bench, showcase, gestlog, scenelog, cheats, CheatPanel). Счёт ниже — **число строк корпуса**, где слово
встретилось (не число вхождений; `-i`, по корню). `in-01` = index.html, в нём ~70 строк — комментарии, не текст
игрока; там, где они сдвигают счёт, сказано. Строка `путь:N` — строка начала литерала/элемента по strings.json
(у JSX-текста может отличаться от строки самого текста на 1–3: например, Temple.tsx:113 → текст на :116).
