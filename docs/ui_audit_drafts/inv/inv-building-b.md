3. «+» × (n−1): шаг только по одному.
4. «Заказать».
Итого **2 нажатия** (через ратушу 3) **+ n−1 на количество + прокрутка**. Нет кузнеца — ещё «+» в ряду рабочих (сверху).

## Путь «нанять отряд» (от посёлка)
Казармы стоят, снаряжение на складе:
1. Тап по крыше казарм **или** «Ратуша» → «Стройка» → строка казарм (2).
2. Прокрутка ≈2 экрана: «Что даёт посёлку», «Дружина», «Оборона», «Свободных», «Жалованье» (4–7 строк + абзац), каждая
   следующая карточка вида ≈150–200 px.
3. «+» × (n−1).
4. «Нанять».
Итого **2 нажатия** (через ратушу 3; через «дружину» в строке состояния → вид → «В казармы — нанять» → «Нанять» — 4) **+
прокрутка**. Конница — только в конюшне, а карточка вида шлёт в казармы (тупик). Не хватает снаряжения: «⚒️ В кузницу —
ковать …» → кузница открывается с прокруткой от казарм → найти вещь → «Заказать» → ждать → обратно в казармы (кнопки назад
нет: крыша или Ратуша → Стройка → казармы) → прокрутка → «Нанять»: **≈5–7 нажатий и три прокрутки**. Обучение:
`tutorial.ts:115-137` (ратуша → `list-barracks` → `recruit-spearman`), весь путь новичка до первого копейщика ≈10 нажатий.
