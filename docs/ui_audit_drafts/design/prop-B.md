# Проект B: одна рука, большой палец

**Угол.** Всё частое лежит снизу и делается в одно-два касания без прокрутки. Верх только читают. Панели выезжают
снизу вверх, главная кнопка закреплена над навигацией, смах работает только там, где он честный. Образцы: Clash of
Clans (тап по зданию, действие у нижнего края, «Тренировать» ведёт в общий экран войска), Rise of Kingdoms
(город и карта переключаются в одной точке внизу), Polytopia (одна полоса действий по выбранному), Kingdom Two
Crowns (на экране ничего лишнего), Northgard mobile (запасы строкой сверху, всё остальное снизу).

**Опора.** `docs/ui_audit.md` разделы 0, 3, 4 (правила, словарь), описи `inv-*.md` @ 8ae4967, справочник
`docs/handbook/ui.md`, `realm.md`, `quests.md`, `world.md`, `gestures.md`. Пиксели — проект, а не замер. Числа отчёта
`tap` взяты из кэша приёмки `.git/tribe-reports/tap/d851258a…txt` (коммит 8b15c7b, 01.10.2026), команда —
`npm run tap:report`, таблица «Постройка · центр».

**Мерки.** Экран 390×844, **T** = `--safe-top`, **B** = `--safe-bottom`, в расчётах T = B = 0 (браузер, полный экран).
Вебвью Telegram в обычном режиме ≈741 (оценка описи, не измерено): верх и низ стоят на месте, сжимается сцена или
карта; где важно, дано второе число. Нажатия считаются как в `inv-flows.md`: каждое касание, включая закрытие;
«до / с возвратом» — до действия и до посёлка без открытых панелей. Смах вниз — жест, не нажатие.

**Чего проект не делает.** Долгого нажатия нет нигде: запрет `gestures.ts:76-79` и `docs/handbook/gestures.md`
остаётся, вопрос 10.1 аудита этому проекту не нужен. Не трогаются: одна форма цены `Cost`, полоска запасов поверх
окон, слой обучения выше державы, правило 18 (числа функциями игры), словарь 4.4.

### 0.4. Шторка — одна на всё

Носитель всех панелей: здания, справки, «Дружина», «Вести», держава, карточка клетки, «Походы», легенда.

**Ступени** — доли свободной высоты `A = H − B − nav − (T + hud)`; на 844 A = 720, на 741 A = 617.

| Ступень | Доля A | Высота / верх (844) | Высота / верх (741) | Кому по умолчанию |
| --- | --- | --- | --- | --- |
| низкая | 45 % | 324 / 464 | 278 / 407 | дворы, жилища, склад, лазарет, пустая земля, справки |
| средняя | 70 % | 504 / 284 | 432 / 253 | кузница, казармы, ратуша, «Дружина», «Вести», держава, поселение на карте, «Походы» |
| полная | 100 % | 720 / 68 | 617 / 68 | только смахом вверх |

По долям экрана это 38 / 60 / 85 % — близко к аудиту 3.10 (40 / 62 / 92). **Решено по правилу 19:** ступени считаются
от свободной высоты, поэтому полная встаёт под полоской запасов, а не на неё, и навигация видна под шторкой всегда.

**Анатомия** (сверху вниз):

| Часть | Высота | Что |
| --- | --- | --- |
| ручка | 12 | полоска 36×4; тянется вся шапка вместе с ручкой (64 px полосой) |
| шапка | 52 | [‹ 44, если панель открыта из другой] · значок 28 · имя 15/600 и строка 11 под ним · справа действие шапки (у здания «Улучшить» 104×44) · ✕ 44 |
| строка цены | 24 | `Cost` того, что в шапке; нет действия — нет строки |
| вкладки | 44 | только если разделов больше одного; слово 13/600, без эмодзи |
| тело | остаток | прокрутка; вкладка помнит прокрутку, новая панель открывается с начала (`key` у `Sheet`) |
| закреплённая полоса | 64 / 88 / 128 | главное действие; 88 — `Cost` 20 над кнопкой 48; 128 — два ряда по 52 |

**Без затемнения.** Сцена и карта над шторкой живые: тап по другой крыше или клетке меняет содержимое за одно
касание, тап по пустой сцене закрывает (как сегодня у здания). Затемнение остаётся только у окон, ждущих ответа (0.6
аудита 3.10): зима, вторая вкладка, отброшенное сохранение.

**«Назад» — у большого пальца.** Стопка панелей, открытых одна из другой (найм → кузница → назад к найму; кузница →
технологии → назад; ратуша → здание → назад), ведётся одной дверью в сторе. Возврат — «‹» в шапке шторки (на средней
ступени y 296…348) и тем же ходом кнопка «Назад» Telegram (`BackButton`, Bot API 6.1); на Android её же вызывает
системный «назад» с края экрана (по документации клиента, на устройстве не проверено). **Отступление от аудита 3.10**
(«своих стрелок нет»): кнопка Telegram стоит в левом верхнем углу шапки клиента — дальше всего от пальца, а вне
Telegram её нет вовсе. Решено по правилу 19: одна стопка, две кнопки к ней.

**Закрыть:** смах вниз по шапке · ✕ 44 · тап по пустой сцене · повторное нажатие активной кнопки навигации. Смах
вниз в теле, прокрученном к началу, опускает на ступень.

### 0.5. Подсказка `Tip` — тапом, без удержания

Один компонент, одно хранилище слов (`ui_texts.md`), числа — функциями игры. Открывается **тапом по элементу, который
сам ничего не делает**: ячейка запаса и состояния, значок и число в строке, цена, знак уровня, строка «ур. 3 из 10»,
запертая плитка, знак внимания. У кнопок с действием подпись всегда есть (слово или 11 px под значком), поэтому
объяснять кнопку не нужно. Чисто значковые кнопки — только стандартные: ✕, ‹, ⚙, ♪, «i», масштаб, «к своему
городу»; их смысл — в `aria-label` и в листе «Знаки» легенды.

- Плашка `--panel` с рамкой, ширина ≤ 300, поля 8/12; имя 13/600, ниже 1–2 строки 13/400, ≤ 140 знаков. У верхних
  ячеек встаёт **под** ячейкой, у остальных — над пальцем.
- Несёт до двух дверей 44 px («Склад ›», «Изучить ›»). Двери — единственное нажимаемое в ней.
- Закрывается следующим касанием где угодно; это касание больше ничего не делает (тот же сторож, что
  `swallowGhostClick`).
- На ПК — ещё наведение 400 мс (аудит 3.7, п. 3).

### 0.6. Необратимое — два касания одной кнопки

Первое касание превращает кнопку в «Точно?» на 3 с (рамка `--bad`), второе делает (аудит 3.10). Для одной руки это
лучший вид подтверждения: палец уже стоит на месте, окна нет. Список: любая трата алмазов (достройка), отмена стройки
и заказа с потерей половины, роспуск, «Отпустить» невольников, крещение, «Штурмовать», «Отступить», удар с тыла
(риск гибели полководца), увод полководца из осады тапом по земле, «Пропустить» обучение, «Начать заново», «Вернуть»
и «Забыть» отклонённую партию. Три системных `confirm()` уходят.

### 0.7. Счётчики (аудит 3.9)

Два вида, 18 px, 11/700, больше 9 — «9+». **Красный** — беда со сроком (набег, осада, мятеж). **Янтарный** — ждёт
действия. Счётчик стоит только там, куда ведёт нажатие.

| Где | Считает | Цвет |
| --- | --- | --- |
| «Ратуша» | свободные руки (`idleCount`), если в городе есть пустые места; прячется, пока идёт стройка (свободные строят) | янтарь |
| «Вести» | вести на столе, ждущие ответа, плюс несыгранное задание дня | янтарь; красный, если среди них набег, осада или мятеж |
| «Карта» (в городе) | свои донесения, ещё не открытые | янтарь |
| «Походы» (на карте) | то же число | янтарь |
| вкладка «Алмазы» | стройки, которые можно достроить | белая цифра на `--gem` (не красное на красном) |

Уходят: «Задания 3» (потолок 3 из 16, висит всю партию), «Племя 32» и «Ратуша 4» (сводятся в один счётчик), бейдж
герба «не открывали», бейдж карты «непрочитанные, иначе все отряды, включая чужие». Метки на «Державе» о доступной
ступени **нет**: `docs/handbook/realm.md` прямо записывает её в «не доделывать по дороге» (вопрос 11.9).

### 0.8. Слои (токены `--z-*`)

сцена 0 · ряд состояния и срочные чипы 6 · полотно карты 8 · ряд тревог, строка руки, ряд карты 9 · шторка 10 ·
навигация 12 · затемнение окон 20 · **ряд запасов 21** · обучение 22–24 · `Tip` 25 · тост 30 · ролик 40 · старт 70.

- Ряд запасов и ряд состояния — разные слои внутри шапки без своего z-index (как сегодня `.topbar`): запасы над
  затемнением окон, состояние — под ним. Так правило «полоску не закрывает ни одно окно» держится слоем, а двери
  подсказок состояния под открытым окном недостижимы.
- Ряд тревог под шторкой (9 < 10): открыл панель — тревоги ушли под неё, беда со сроком остаётся красным счётчиком на
  «Вестях».
- Держава — шторка (10), поэтому слой обучения (22–24) выше неё сам собой; правило «обучение выше меню державы»
  выполняется без своего числа.

### 0.10. Тост

Одна строка 13, ≤ 40 знаков, `pointer-events: none` всегда (сегодня он 2,2 с ловит касания над нижним краем шторки).

### 1.2. Ряд запасов (y 4…36)

- **8 ячеек по 46×32**, x 11…379: семь `RESOURCE_IDS` и **золото**. Ячейка: значок 16 (`res-*`) · 2 · число 13/600
  `tabular-nums` · стрелка 6×4 в правом верхнем углу ячейки. Цель — вся ячейка (исключение 3.6 для ячеек-справок).
- **Число — `shortNum`** (до 999 целиком, дальше «1,2к», «32к»). **Решено:** отступление от 4.5 («до 9 999
  целиком») только здесь — «1 240» в 46 px не входит; полное число стоит в подсказке.
- **Прирост цветом стрелки:** ▲ `--good` при `netPerDay(s)[id] > 0`, ▼ `--bad` при < 0, без стрелки — стоит. Склад полон
  (`storageCap(s) − 1`, как сейчас) — число `--warn`. У золота стрелка по сравнению дохода и жалованья (`upkeepInfo`).
- **Золото в ряду — решено по правилу 19:** это валюта найма, жалованья, пира и половины вестей; «хватит ли» без него
  не ответить. `ResourceBar.tsx:40-42` («золота здесь нет — так задумано») переписывается.
- **Подсказка:** «{Имя} {число} из {storageCap} · {signed(netPerDay)} в день» и дверь «Склад ›». У золота — «Золото {N}
  · налог {+} · жалованье {−} в день» (`upkeepInfo`, `signed`), дверь «Казна ›» (держава, «Управление»).
- `pointer-events: none` снимается: тап только открывает подсказку. Правило `ui.md` «ничего не нажимает» меняется на
  «ничего не меняет в партии» (раздел 9): под открытым окном подсказка безвредна — склад как раз и нужно посмотреть
  из-под вести с ценой.

- **Вон:** плашка координат, строка реестра с полотна, кнопки «Приказы: {имя}» в карточке, слово «Домой» (сегодня три
  смысла: камера, отзыв агента, выход с карты).
- **Тексты:** «Город», «Походы», «Вести», «Ударить», «Осадить», «Разведать», «Перехватить», «Отправить», «Отозвать»;
  строка руки «{Роль}: нажми цель».
