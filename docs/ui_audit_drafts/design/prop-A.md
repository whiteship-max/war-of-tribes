# Проект A: плотность EU4 на портретном телефоне

Угол проекта: максимум сведений на квадратный сантиметр. Значок + число везде, подсказка по тапу как главный способ
объяснять, вкладки вместо столбцов, сводные таблицы (ledger), ряд тревог-значков, outliner своих людей и отрядов.
Узнаваемые решения EU4 переложены на портрет 390 × 844: верхняя полоса с гербом слева, ряд тревог по центру,
окно державы с разделами-значками, карточка провинции (клетки), outliner сбоку карты.

**Мерки.** Экран 390 × 844 CSS px, T = `--safe-top`, B = `--safe-bottom` (в браузере 0, iPhone с полоской «домой» —
B ≈ 34, оценка). Вебвью Telegram ≈ 741 px — оценка описи, не измерено; где важно, дано оба числа. Высоты выведены
сложением кеглей, отступов и рамок по правилам раздела 3 `ui_audit.md` (шаг 4, кегли 11/13/15/18, значки 16/20/28/40),
на устройстве не мерены. Нажатия — по описи `inv-flows.md`, тем же счётом: каждое касание, включая закрытие;
«до / с возвратом» — до действия и до посёлка без открытых окон.

**Чего проект не делает.** Долгого нажатия нет нигде: всё объясняется тапом по тому, что само ничего не делает (3.7,
п. 1 и 3). Запрет `gestures.ts:76-79` не трогается, вопрос 10.1 для этого проекта не нужен. Не трогаются: `Cost`
(одна форма; расширяется значками очков), правило 18 (все числа — функциями, перечислены у ячеек), слой полоски
ресурсов (21, выше окон), слой обучения (выше державы).

## 0. Главное

1. **Верх — одна полоса EU4 в две строки, 78 px** (сегодня 123): строка A — герб, сезон, жители, мораль, [порядок],
   золото, дружина; строка B — семь запасов, прирост цветной стрелкой. Ряд «герб + карта» уходит, карта — вниз.
2. **Тревоги — ряд круглых значков 44 × 44 по центру** под полосой: красный — беда по сроку, охра — заметка;
   таймер внутри значка; тап ведёт к решению. Ряд фиксированный (44 px) при любом числе тревог; работает и на карте.
   Плашка осады 162 × 167 в зоне пальца становится тревогой.
3. **Низ — пять вкладок 52 px: Стройка · Племя · Карта · Дружина · Вести.** Центральная — переключатель «Карта ⇄
   Город». «Задания» уходят в державу, их «3» навсегда гаснет.
4. **Подсказка `Tip` по тапу** — у запасов, золота, клеток сводок, значков в строках, цен. Одна плашка, ≤ 140 знаков,
   при нужде одна ссылка «Склад ›».
5. **Шторка без затемнения, три ступени 300 / 470 / вся.** Шапка 56 с главным действием, строка цены 24, при нужде
   вкладки 44, липкая полоса действия 56 над навигацией. Тап по другой крыше или клетке меняет содержимое за 1
   касание. «Назад» Telegram — стопка панелей (найм → кузница → назад к найму).
6. **Держава — окно страны EU4:** шапка с гербом и тремя видами очков, шесть разделов значками внизу, «Технологии»
   тремя столбцами на одном экране без прокрутки.
7. **Outliner на карте** — столбец 44 px у правого края: четыре человека, свои отряды, идущие на нас. Тап = в руку и
   камера. Это единственный список людей на карте (вместо «Фигур» в «Походах»).
8. **Сводные таблицы:** «Племя» — все места работы строками 44 с «Все»; «Дружина» — состав · люди · походы;
   «Стройка» — все постройки строками 64 с фильтром «Можно»; «Вести» — карточка события с вариантами внизу и
   автопереходом к следующей.
9. **Набег — одна карточка решения** в «Вестях»: сводка «они / мы» ячейками, обе стороны решения на месте и в
   порядке «собрать → перехватить» (сегодня перехват без сбора — тупик на карте). Поход — 6 касаний до удара вместо 10.
10. **Первые шаги** — те же восемь меток обучения на новых местах, без правки `tutorial.ts`: 16 касаний без тупиков
    вместо ≈18 с двумя; строка обучения внизу, «Дальше ›» и срок ожидания числом.

Итог по частым действиям — раздел 9; правила, которые меняются, и чьё слово нужно, — 10; риски для `tap` и обучения —
11; правка симуляции — вопросы владельцу, 12.

**Место под интерфейс.** Постоянный интерфейс посёлка: сегодня 180 px (21,3 %), с тремя тревогами 311 (36,8 %).
После: **130 px (15,4 %)**, с любым числом тревог **176 px (20,9 %)**. С B = 34: 164 / 210 (19,4 / 24,9 %).
