# Черновики к ui_audit.md

Сырой материал работы над интерфейсом, сохранённый при остановке 01.10.2026, чтобы не снимать его заново.
**Это черновики подагентов, глазами сессии не вычитаны (правило 10).** Ссылаться на них как на правило нельзя;
брать из них — только сверив с кодом. Опись снята на `8ae4967`.

- `inv/` — опись интерфейса по 14 зонам: экраны, кнопки, подписи дословно, высоты из CSS, нажатия, проблемы
  П1–П3 с путями. Выборочная сверка 17 утверждений с кодом: 14 верны, 2 неверны (тост закрывается сам через
  2,2 с; `title=` в `src/ui` — 24, а не 19), 1 неполно (слой обучения на шагах без действия ловит касания).
  Главное для продолжения — `inv-flows.md` (карта переходов и число нажатий), `inv-touch-rules.md` (замки:
  отчёт `tap`, тесты по исходникам, `data-tut`, правило 18), `inv-terms.md` (материал словаря).
- `design/` — три проекта экранов с разных углов: A — плотность EU4, B — большой палец, C — сцена прежде
  всего. **Не дописаны**: остановлены на середине, судей не было.
- `tools/` — щуп строк. `extract.cjs` разбирает `src/**/*.ts(x)` деревом TypeScript (без комментариев) и
  `index.html`, пишет все строки на кириллице с путём и строкой; `batch.cjs` раскладывает их на пачки по зонам
  (кладёт рядом с собой `texts/in-NN.json`, читает `strings.json` оттуда же):

  ```bash
  node docs/ui_audit_drafts/tools/extract.cjs . docs/ui_audit_drafts/tools/strings.json
  ```

  Щуп лёгкий, не прогон: одна секунда, одно ядро. `typescript` берётся из `node_modules` копии (в отдельном
  worktree без `node_modules` — переменной `TS_PATH` с путём к пакету).
