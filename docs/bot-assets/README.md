# Картинки для бота — куда что загрузить в @BotFather

Файлы в этой папке в сборку игры не входят: их загружают в Telegram руками, один раз. Собирает их
`npm run splash:build` из кадра города (`assets-src/splash/city-wide.jpg`) и герба
(`assets-src/brand/crest.svg`); пересобирать их незачем, пока не поменялся герб или кадр.

| файл | размер | куда |
| --- | --- | --- |
| `avatar-640.png` | 640×640 | аватар бота (`/setuserpic`) |
| `description-640x360.jpg` | 640×360 | картинка описания — её видят в пустом чате с ботом над кнопкой «Старт» |
| `app-cover-640x360.jpg` | 640×360 | обложка мини-приложения (`/newapp` или `/myapps`) — если оно заведено отдельным приложением |

Значок самой игры (вкладка, ярлык «Домой» на телефоне) загружать не надо — он едет со сборкой
(`public/favicon.svg`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`).

**Оговорка.** Отсюда BotFather не открыть, и его меню иногда меняют. Ниже — команды и пункты меню,
как они устроены сейчас; если пункта нет на месте — тот же раздел есть в `/mybots` → бот → **Edit Bot**.

## 1. Аватар

1. Открыть [@BotFather](https://t.me/BotFather), отправить `/setuserpic`.
2. Выбрать бота игры.
3. Отправить `avatar-640.png` **как фото** (не «файлом»: скрепка → Фото/Галерея).

Telegram режет аватар в круг: щит занимает 62 % стороны и в круг входит целиком.

Через меню: `/mybots` → бот → **Edit Bot** → **Edit Botpic**.

## 2. Картинка описания (что видит новый игрок в пустом чате)

1. `/mybots` → бот → **Edit Bot** → **Edit Description Picture**.
2. Отправить `description-640x360.jpg` как фото. (Можно и GIF 640×360 — например, короткий ролик города, если
   захочется потом.)

## 3. Тексты (по желанию — картинка без них тоже работает)

**Описание** — текст в пустом чате под картинкой, до 512 знаков: `/setdescription` → бот → текст. Предложение:

> TRIBE — стратегия о городе позднего средневековья. Город стоит с первой минуты: ставь людей на работу, куй
> снаряжение, нанимай дружину, отправляй разведку и походы, решай события. Заход — три–пять минут. Жми
> кнопку внизу — и город твой.

**О боте** — строка в профиле бота, до 120 знаков: `/setabouttext` → бот → текст. Предложение:

> Город, дружина и поход: стратегия о Европе 1200 года прямо в Telegram.

Слово на кнопке внизу (если там не «Играть») — `/setmenubutton`: **адрес не менять**, он должен остаться
`https://game.kingsvassals.com` (CLAUDE.md, «Выкладка»), меняется только подпись.

## 4. Обложка мини-приложения — только если оно заведено отдельно

Кнопка меню (`/setmenubutton`) обложки не просит. Обложка нужна, если игра заведена мини-приложением со своей
ссылкой вида `t.me/<бот>/<имя>` (`/newapp`) — тогда BotFather при создании просит «photo 640×360»:

* новое приложение: `/newapp` → бот → название `TRIBE` → описание (строка «О боте» выше) → фото
  `app-cover-640x360.jpg` → GIF пропустить (`/empty`) → адрес игры (тот же боевой) → короткое имя;
* уже заведённое: `/myapps` → приложение → **Edit Photo** → `app-cover-640x360.jpg`.

Если в настройках главного мини-приложения бота (`/mybots` → бот → **Bot Settings** → **Configure Mini App**)
есть пункт про картинки для витрины — подходят те же `app-cover-640x360.jpg` и `description-640x360.jpg`.

## Проверить после загрузки

* Открыть чат с ботом с другого аккаунта (или удалить чат и открыть заново): видна картинка описания и текст.
* Аватар в списке чатов — щит виден целиком, края не срезаны.
