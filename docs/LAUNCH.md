# Запуск теста на 25 человек — памятка владельцу

Ветка `game/prelaunch` (10.10.2026, чат 2). Порядок шагов важен: каждый следующий опирается на предыдущий. Пошаговая
установка сервера — [SERVER.md](SERVER.md), команды бота — [admin.md](admin.md), режим Сицилии —
[test_world.md](test_world.md), прогон 25 ботов — [playtest_sim.md](playtest_sim.md).

## 0. Перед всем: слить и принять

1. Слить `game/prelaunch` в `master` (она стоит на `game/fixes`), дома, на свободной машине — пол правила 9 и полная
   приёмка `npm run reports -- --base f7cf67e` (docs/MORNING_CHECK.md, «Перед тестом на 25»).
2. **Чистый старт обязателен** (шаг 4 ниже): сменились места на Сицилии (25 вместо 12) и правило идентификатора замка
   (раздел «Безопасность»). Без `/wipeworld ДА` стоящие замки и войны остались бы со старыми номерами.

## 1. Свой сервер (этап 2 переезда) — кто что делает

**Делает владелец (руками, сам):**

1. Арендует VPS (Ubuntu 24.04, от 2 ядер, 2–4 ГБ памяти, от 20 ГБ диска — server-move.md, раздел 7), заводит домен и
   запись `A` на адрес сервера (SERVER.md, шаги 1, 8).
2. Кладёт свой SSH-ключ на сервер (SERVER.md, шаг 2) и даёт сессии адрес сервера и имя пользователя.
3. **Вписывает секреты в `~/tribe/.env` сам** — сессия их не видит и не просит:
   - `TELEGRAM_BOT_TOKEN` — токен из @BotFather (тот же, что на Netlify);
   - `TELEGRAM_WEBHOOK_SECRET` — придуманная строка: латиница, цифры, `_` и `-`, до 256 знаков;
   - `ADMIN_IDS` — свой номер Telegram (узнать у @userinfobot), несколько — через запятую;
   - `TON_*` — **оставить пустыми**: оплата на тесте выключена (сервер сам так пишет при запуске).
4. Нажимает кнопки в @BotFather (шаг 5 ниже) и шлёт боту `/wipeworld ДА` (шаг 4).

**Делает локальная сессия Claude по SSH (со словом владельца):**

1. Подготовка сервера по SERVER.md, шаги 3–7: обновления, пользователь `tribe`, вход только по ключу, файрвол
   (22, 80, 443), подкачка при 2 ГБ, Docker.
2. Код на сервер (шаг 9: deploy key только на чтение) — ветка `master` после слияния.
3. `.env` из образца: `cp .env.example .env` и **несекретные** значения:
   `TRIBE_DOMAIN=<домен>`, `TRIBE_APP_URL=https://<домен>`, `TRIBE_SPAWN=sicily`, `TRIBE_DELIVER=on`,
   `TRIBE_STORE=sqlite`; `TRIBE_WAR_PACE` — решает владелец: `1` — обычная война (до ближнего соседа 24 м 02 с, самая
   дальняя пара — 2 ч 00 м; `60` — 24 с и 2 м; docs/test_world.md, «Сколько идти», `npm run settle:report`).
4. Первая сборка и запуск: `docker compose up -d --build`; внутри образа `web` — `caddy validate --config
   /etc/caddy/Caddyfile` (Caddyfile ещё не проверялся самим Caddy — server-move.md, раздел 5).
5. Проверка SERVER.md, шаг 12: `/api/time` отвечает числом, `/api/save` без подписи — `unauthorized`, игра открывается
   по HTTPS. И журнал запуска: `docker compose logs app` — строк «внимание:» быть не должно, последняя строка —
   `режим: места sicily, темп войны ×…, админов 1, оплата выключена, доставка уведомлений включена`.
6. `SITE_URL` в `src/game/data/social.ts` — на новый домен, коммитом в `master` (ядро — словарь), и обновление сервера
   `sh deploy/update.sh` (SERVER.md, шаг 17).
7. Перенос данных с Netlify (SERVER.md, шаг 13) **не нужен**: тест начинается с чистого мира.

## 2. Переменные — сводка

| Переменная | На тесте | Что будет, если пусто |
| --- | --- | --- |
| `TELEGRAM_BOT_TOKEN` | токен бота | сервер не поднимается и говорит почему |
| `TELEGRAM_WEBHOOK_SECRET` | своя строка | вебхук закрыт: ни команд админа, ни кнопок под уведомлениями (строка «внимание:» в журнале) |
| `ADMIN_IDS` | свой номер | бот молчит на команды (строка «внимание:») |
| `TRIBE_SPAWN` | `sicily` | новички встают по обычному расселению, защита слабого включена |
| `TRIBE_DELIVER` | `on` | бот не пишет о нападениях и боях |
| `TRIBE_APP_URL` | `https://<домен>` | кнопка «Открыть игру» ведёт на Netlify |
| `TRIBE_WAR_PACE` | `1` (или своё) | 1 |
| `TON_*` | пусто | оплата выключена — так и надо |

Переменные доходят до приложения только с перезапуском: `docker compose up -d` после правки `.env`.

## 3. Вебхук бота

Один раз, с сервера или с любого компьютера (`<ТОКЕН>`, `<СЕКРЕТ>` — из `.env`):

```bash
curl -sS "https://api.telegram.org/bot<ТОКЕН>/setWebhook" \
  -d url=https://<домен>/api/bot \
  -d secret_token=<СЕКРЕТ> \
  --data-urlencode 'allowed_updates=["message","callback_query","my_chat_member"]'
```

Ответ — `"Webhook was set"`. Проверка: написать боту `/help` — пришёл список команд (с чужого аккаунта — тишина).
Вебхук один на бота: после этой команды Netlify команд бота больше не получает.

## 4. Чистый старт

1. `/wipeworld` — бот объяснит, что сотрёт; затем `/wipeworld ДА` → «Мир начат заново: эпоха N».
2. Объявить в чате тестеров: «заходите» и переслать [TESTERS.md](TESTERS.md).
3. `/spawns` через несколько минут: «Занято K из 25», строки «Вне мест острова» нет.

## 5. BotFather

1. `/mybots` → бот → **Bot Settings → Menu Button** → `https://<домен>`.
2. Мини-аппка (`/myapps` → **Edit Web App URL**) или «главная мини-аппка» (**Configure Mini App**) — тот же адрес.
3. Закрыть игру в Telegram полностью и открыть заново — проверить, что открылся свой домен.

Партия на телефоне привязана к адресу сайта: на новом адресе телефон начинает с чистого листа — на чистом мире это
ничего не меняет.

## 6. Как следить во время теста

| Команда | Когда смотреть | На что смотреть |
| --- | --- | --- |
| `/spawns` | первый час | все вошедшие на местах 1…25 |
| `/stats` | раз в несколько часов | файл CSV: кто заходит, время в игре, войско, бои |
| `/flags` | утром и вечером | подозрительные; честный игрок с флагом — отчёт сессии, а не заморозка сразу |
| `/reports`, `/report <номер>` | после каждого «🐞» | десять последних отчётов; номер — для отчёта целиком |
| `/player <кто>` | по жалобе | всё об игроке: склад, войско, бои, журнал города |
| `/frozen`, `/log` | по делу | кто заморожен, что делали админы |

На сервере:

```bash
docker compose logs --tail 50 app   # строки «обработчик … упал — ответ 500» — повод позвать сессию
df -h /                             # место на диске: меньше 2 ГБ — чистить (SERVER.md, шаг 18)
docker compose run --rm app backups # копия за сегодня есть (снимается сама в BACKUP_AT)
```

Чего ждать в «час войны»: десяток походов в одну минуту проходит без отказов — запись войн идёт по очереди, а опрос войны
не съедает приказы (прогон ботов: 12 из 12 и лазутчики 6 из 6 — playtest_sim.md, «Мелкое», п. 1; до правки было 4 из 12).
Отказ «слишком часто» остался только на петлю — больше 30 приказов в минуту от одного игрока.

Нарушитель: `/freeze <кто> причина` — его записи, приказы войны, лазутчика, лавки и заказы оплаты отклоняются, поход на
него поворачивает. `/unfreeze <кто>` — вернуть. Указом `/give` можно вернуть потерянное ошибкой игры (алмазы указом не
меняются).

## 7. Если сервер упал

Игра у игроков при этом **не ломается**: партия живёт на телефоне, запросы, не дошедшие до сервера, игра повторит сама,
когда он вернётся. Война между игроками и рейтинг ждут сервера.

1. `docker compose ps` — что лежит. `docker compose logs --tail 100 app` — последняя строка до падения.
2. `docker compose up -d` — поднять. Приложение и так перезапускается само (`restart: unless-stopped`).
3. Принятое до падения не теряется и не начисляется дважды: запись в базу — до ответа, SQLite с `synchronous = FULL`;
   повтор заказа лавки тем же ключом не списывает второй раз (тест `netlify/vps/restart.test.ts`); бой войны игрок
   принимает по номеру один раз.
4. Кончилось место на диске — запись в базу падает, наружу ответ 500, а игра у игроков считает это «нет сети» и
   копит у себя (`src/net/api.ts`: ответ не JSON — `offline`). Освободить место (`docker image prune -f`, старые копии
   в `/data/backups`) и на всякий случай `docker compose restart app`. Заполненный диск на деле не проверялся.
5. База испорчена — восстановление из копии (SERVER.md, шаг 16): `docker compose stop app` →
   `docker compose run --rm app restore <имя>` → `docker compose start app`. Нынешняя база сама уходит копией
   `before-restore-…`. После падения (а не чистой остановки) восстановление полторы минуты отвечает «сервер работает» —
   подождать и повторить. Проверено 10.10.2026 тем же собранным сервером без Docker (порядок «копия → запись →
   отказ под работающим → остановка → восстановление → запись до копии на месте»), разовая проверка, не тест.
6. Telegram недоступен — бот не пишет, игра работает; недоставленное уведомление проход доставки снимает с отметки
   «отправлено» и шлёт в следующий проход (`deliver.ts`); у запросов к Telegram и к сети TON свой срок ожидания.

## 8. Остановить тест и разослать итоги

1. Объявить в чате за час: «в такое-то время подводим итоги».
2. `/final` — таблица рейтинга, как её увидят игроки (только тебе).
3. `/final ДА` — каждому игроку его место. Строка «Не ушло: N» — повтор `/final ДА` пришлёт таблицу всем ещё раз.
4. `/stats` — сохранить CSV себе: после следующего `/wipeworld ДА` его не будет.
5. Мир можно оставить жить или начать новый тест `/wipeworld ДА`. Вернуть обычную игру: убрать `TRIBE_SPAWN`
   (и `TRIBE_WAR_PACE`) из `.env` и `docker compose up -d`.

## Безопасность (что проверено перед тестом, 10.10.2026)

- **Личность** — только подпись `initData` токеном бота, срок сутки, часы клиента вперёд не больше пяти минут
  (`initdata.ts`, тесты подделки, протухания и будущего). Строка, перехваченная с чужого телефона, сутки даёт доступ к
  партии и алмазам того же игрока — цена суточного срока (Telegram не обновляет строку в открытой аппке); на тест —
  принято.
- **Админ** — только `ADMIN_IDS`, только личный чат; вебхук — только с секретом (сравнение постоянным временем).
- **Частота** — ведро на игрока и адрес у каждого адреса API, у войны два — опрос (60 в минуту) и приказы (30), у часов —
  на IP; тело — 512 КБ у приложения, 1 МБ у Caddy.
- **Секреты** — в ответах и журнале нет (журнал пишет только свои слова, тест `server.test.ts`); в клиентской сборке
  переменных окружения нет; `.env` в образ не копируется.
- **Заморозка** — запись партии, приказы войны и лазутчика, алмазы и заказы оплаты (тест `admin.test.ts`).
- **Оплата** — без `TON_WALLET` выключена: заказ отвечает «Оплата ещё не открыта» (тест `pay.test.ts`).
- **Что видно о другом игроке** — имя города и правителя, мощь, население, клетка, войны и пойманные лазутчики (хозяин
  удачного тайного дела не раскрывается). **Исправлено:** идентификатор замка был голым хешем ключа `tg-<номер>`, и
  номер Telegram любого соседа восстанавливался перебором; теперь это HMAC с токеном бота (`netlify/lib/roster.ts`,
  тест `roster.test.ts`). Отсюда и обязательный `/wipeworld ДА` при выкладке.
