# Макеты интерфейса

Макеты к [docs/ui_audit.md](../ui_audit.md): главные экраны «до» и «после» рядом, в размере экрана
телефона (390 × 844 CSS px, шапка Telegram и нижняя системная полоса нарисованы поверх, как на
телефоне). Это картинки из HTML, а не код игры: ни один файл отсюда не импортируется в `src/`.

## Как открыть

Двойной щелчок по `index.html` — откроется в браузере как файл, без сервера и без сборки. Оттуда
ссылки на каждый экран. На телефоне — тот же файл, переданный себе в Telegram, или страница-артефакт,
если она выложена (ссылка — в итоговом отчёте сессии).

## Из чего собраны

- `assets/sprite.js` — лист значков проекта (`public/assets/icons/sprite.svg`, 184 значка), вшитый
  скриптом, чтобы `<use href="#i-<имя>"/>` работал и с диска (браузер не отдаёт внешний SVG странице,
  открытой как файл). Пересобрать после правки листа:

  ```bash
  python docs/ui_mockups/assets/build_sprite.py
  ```

- `assets/village.jpg`, `assets/map.jpg` — снимки сцены из `snaps/` (посёлок — `snaps/village/before-now-day-wide.png`,
  карта — `snaps/map/after-дом-вблизи.png` без её верхней и нижней полос); подложка под интерфейс, не часть макета.
- `icons.html` — весь лист значков по группам, с именами.

Значок, которого в листе нет, нарисован в макете своим SVG того же стиля и помечен рамкой «нет в листе»;
список таких — docs/ui_audit.md, «Недостающие значки».
