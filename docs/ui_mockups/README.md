# Макеты интерфейса

Макеты к [docs/ui_audit.md](../ui_audit.md): главные экраны «до» и «после» в размере экрана телефона
(390 × 844 CSS px). Сверху нарисованы строка системы и шапка Telegram, внизу — полоска «домой», как на телефоне.
Это картинки из HTML, а не код игры: ни один файл отсюда не импортируется в `src/`.

## Что готово (01.10.2026, работа остановлена)

- `before/village.html`, `before/map.html`, `before/building.html`, `before/realm.html` — нынешние посёлок,
  карта мира, окно кузницы и меню державы на вкладке «Решения». Свёрстаны с настоящих компонентов и **на
  настоящей таблице стилей игры**: `src/ui/styles.css` подключена по относительному пути, не скопирована,
  поэтому «до» показывает игру такой, какая она в рабочей копии. Проверены снимком headless Chrome. Каждый
  экран держит своё состояние партии: «после» к нему обязано повторить те же числа.
- `assets/after.css` — система «после» по ui_audit.md, раздел 3: токены, шкалы, верхняя полоса, тревоги-значки,
  нижняя навигация на пять мест, кнопки, `Cost`, шторка с закреплённым действием, вкладки, строки, шаг, подсказка.
  Экранов «после» ещё нет.
- `assets/phone.css` — рамка: строка системы 47, шапка Telegram 56, вебвью 390 × 741 с `--safe-bottom` 34.
  `.webview` держит `transform`, поэтому `position: fixed` игры отсчитывается от вебвью.

Не готово: экраны «после», страница `index.html` с парами «до/после» рядом.

## Как открыть

Двойной щелчок по любому файлу из `before/` — откроется в браузере как файл, без сервера и без сборки. Окно
браузера лучше сузить до 390 px или открыть инструменты разработчика в режиме телефона.

## Из чего собраны

- `assets/sprite.js` — лист значков проекта (`public/assets/icons/sprite.svg`, 184 значка), вшитый скриптом,
  чтобы `<use href="#i-<имя>"/>` работал и с диска (страница, открытая как файл, не получает внешний SVG).
  Пересобрать после правки листа:

  ```bash
  python docs/ui_mockups/assets/build_sprite.py
  ```

- `assets/village.jpg` — снимок посёлка `snaps/village/before-now-day-wide.png`; `assets/map.jpg` — снимок
  карты `snaps/map/after-дом-вблизи.png` без её верхней и нижней полос, подпись «Наша деревня» под городом
  закрашена травой. Подложка под интерфейс, не часть макета; снимки дневные, в макетах «ночь» — расхождение
  известно.
- `icons.html` — весь лист значков по группам, с именами.

Значок, которого в листе нет, рисуется в макете своим SVG того же стиля и помечается рамкой `.not-in-sheet`.
