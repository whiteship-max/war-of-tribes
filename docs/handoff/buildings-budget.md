# Общий бюджет геометрии зданий

Обновлено после жилищ, ветка codex/houses. По принятому правилу: общий допустимый прирост +60 000 треугольников к исторической базе 45 904 (расчётный потолок 105 904). Не отдельные лимиты на здания.

Учёт ниже ведётся одинаково: основной проход + полный теневой проход отдельного здания. Это консервативный расход для кадров, где тени обновляются реже. Фигуры уже присутствуют в исходной рабочей базе; прибавка 1,6% повторно не начисляется. Исторические телефонные цифры нельзя непосредственно сравнивать с полным теневым кадром компьютерного стенда.

## Новые примитивы

Общий лимит — 3 переиспользуемых типа. Использован **1: arch** (ратуша; далее пригодится аркадам, церкви, лазарету и воротам). Жилища новых типов не добавили. Свободно **2**.

Основной проход: 2 вызова на каждой ступени; треугольники 408/852/1472 → 648/1104/1692. Один склеенный меш, два существующих материала. Дополнительные грани расходуются на стены, фронтоны, выступающие этажи, оконные ставни, трубы; круглые стены и конусы удалены.

MODEL_RADIUS.houses = 2,6 и радиус площадки 1,97708 не изменены. Фактический мировой радиус III 1,73077 → 1,72234; внешняя граница не расширилась. Рост идёт в высоту и в число самостоятельных домов. Башен, зубцов и аркады у жилищ нет: это отличает несколько жилых крыш от зала с башней у ратуши.

Условия: Windows, CSS 390×735, renderer DPR 2,75 (window DPR 1), весна, полдень, одна теневая лампа, PCF 1024. Изолированная сцена без земли и фигур; ортографическая камера ±8, позиция (9,10,12), цель (0,1,0), основной и принудительный теневой проход. Общий снимок L10: 170 вызовов / 66 254 треугольника с тенями. Не является телефонным FPS-замером.

Проверки: 18 тестов планировки после каждой ступени; итоговые 457 тестов в 23 файлах зелёные, включая рост и радиус жилищ. tsc и production build чистые. Промежуточная II ступень была выше старой III; этот временный провал теста прогрессии устранён новой III, тест не менялся.
