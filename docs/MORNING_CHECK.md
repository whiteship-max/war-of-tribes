## 2. Какие адреса открыть

| Что | Адрес (к адресу из п. 1) |
| --- | --- |
| Игра как у игроков — **прежний вид** | `/` |
| Игра в **новом виде** | `/?look=next` (уровень руками — `&quality=low` · `medium` · `high`) |
| Стенд посёлка, день | `/?showcase=village&levels=10&look=next&quality=medium` |
| Ночь / золотой час / зима | то же + `&solar=0.75` · `&solar=0.47` · `&season=winter` |
| Ролик боя: стая у ворот | `/?replay=1&beasts=1&men=40&foe=30&look=next` (`&at=clash` · `melee` · `rout` · `last` — кадр стоит) |
| Ролик боя: сцена в новом виде | `/?replay=1&men=60&foe=60&place=woods,road&look=next` (без `look` — прежняя; `&winter=1`, `&hour=19`) |
| Волк, собака и копейщик вблизи | `/?showcase=units&units=wolf,dog,spearman&action=guard` (`stand` · `walk` · `strike` · `fall`, `&turn=90` — сбоку) |
| Замер плавности на телефоне | стенд посёлка + `&perf=8` (итог на экране: `fps`, `low5`) |

Снимки на ПК без браузера руками — `npm run village:shots` (посёлок; ближние ракурсы:
`LOOKS=next:medium SHOTS=houses-close,hall-close,church-close,plaza-close,plaza-night,hens-close,sheep-close`) и
`npm run replay:shots` (ролик и ряд фигур; `SHOTS=` — ракурсы печатаются в конце вывода). Картинки — в `snaps/`.

## 5. Как решил сам (правило 19, поправьте)

1. **Волк — боец, цвет — сторона.** Правило «Цвет — это сторона» (docs/battle-replay.md) — на всех деталях бойца;
   волк в ролике красный, тёмное — тот же красный темнее; серые ключи волка из палитры убрал. Вид читается
   силуэтом.
2. **Ролик стаи — только в новом виде** (кнопка «Смотреть бой» у записи со зверями — когда сцена рисует `next`),
   чтобы прежняя игра не менялась. Комментарий поля `BattleRecord.beasts` (`world/types.ts`, ядро) не трогал —
   для прежнего вида он верен; поправить, когда новый вид станет умолчанием.
3. **Стая не строй и бросок низом** — по снимкам: в лоб (а крупный план смотрит на стаю в лоб) ровный ряд волков
   и бросок на дыбы читались красными столбиками.
4. **Сцена ролика — поверх прежней земли:** шейдер земли посёлка не переносил (это переписать землю ролика);
   две породы деревьев вместо четырёх и одна дальность — четыре вызова вместо восьми; трава — одним счётом на все
   уровни (ролик идёт, пока посёлок стоит).
5. **Дым — круглый только в новом виде** (правка едет куском окружения); в прежнем виде дым прежний.
6. Пункты 1–3 — решения записаны в 11.1–11.3 (угол поля 88°, трёхполье по полям, огороды внутри стены и
   цветы — земля, а не декор; фактура — признаками в вершинах; звери — фигуры общего пула).
