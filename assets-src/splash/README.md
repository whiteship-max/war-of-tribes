# Арты перехода и заставка

## Заставка экрана загрузки

В игре стоит `march-full.png`, кадрированный вертикально: `npm run splash:build`
режет из него 585×1266 и кладёт в `public/assets/splash/boot.webp` (20.5 КБ).
Логотип уходит из кадра — при вертикальном кадрировании он режется на полуслове.
Дракон тоже не попадает: он в правой верхней четверти, а кадр берётся ниже
логотипа и по центру.

**Два арта, два места, ни одного повтора.** «Поход» — заставка запуска, «костёр» —
занавес первого входа на карту. Один кадр, увиденный дважды за минуту, читается
поломкой.

Отдельным файлом, а не строкой внутри `index.html`: вложенная отодвигает первый
кадр экрана загрузки на 3G с 274 до 833 мс и появляется в тот же момент. Числа
и разбор — в `docs/loading.md`.

Векторная заставка, что стояла здесь до арта, удалена совсем — и файл, и всё,
что на неё ссылалось. Она свою роль отыграла: показала, что рисовать заставку по
правилам плоского значка нельзя. Мёртвый файл в исходниках однажды вернут по
ошибке; в истории её достаточно.

## Арты перехода

Два арта на переход между посёлком и картой мира, каждый в двух размерах.

| файл | что на нём | куда идёт |
|---|---|---|
| `march-full.png` | дружина перед чужой крепостью, 1672×941 | из него режется заставка запуска |
| `camp-640.png` | племя у костра | из него режется занавес |
| `camp-full.png` | он же, 1672×941 | никуда, исходник |

Малой версии похода здесь нет нарочно: занавес из него больше не режется, а
заставке нужен большой — в кадр входит 15% ширины.

Два разных арта, а не один: переход, одинаковый в обе стороны, читается сбоем
интерфейса, а не дорогой — игрок перестаёт понимать, куда его ведут.

**В клиент едут только малые.** `npm run splash:build` режет из `*-640.png`
полосу и кладёт WebP в `src/ui/art/`. Большие версии лежат здесь исходниками:
пригодятся, если понадобится другое кадрирование, а в сборке им делать нечего —
они весят по два-три мегабайта.

Что и почему режется — в шапке `scripts/build-splash.mjs`, вкратце: уходит верх
с надписью «War of Tribes». Занавес показывается по несколько раз за партию, и
логотип на нём читается как «игра перезапустилась»; к тому же в картинках игры
текста нет вовсе — весь текст пишет интерфейс (`docs/ART_HANDOFF.md`, 3.6).

Подробности перехода и числа замера — [docs/loading.md](../../docs/loading.md).
