# Заставка

## Заставка экрана загрузки — кадр самой игры

С 08.10.2026 заставка — не рисунок, а **кадр движка игры**: город на закате, снятый стендом
`city:shots` (`?showcase=city` — тот же `buildCity`, та же жизнь города, стяги, дым из труб, свет
общего рига `applyDayNight`). Прежний арт «вождь у костра» (`campfire-full.jpg`) убран: игра теперь
про город и дружину, а не про костёр.

| файл | что | чем снят |
| --- | --- | --- |
| `city-full.jpg` | **заставка** — вертикальный кадр 1080×1800 | `SIZE=540x900 QUALITY=high VIEWS=game SOLAR=0.49 EXTRA="elev=30&dist=400&fov=38&at=0,10,-25&haze=1.7" npm run city:shots` |
| `city-wide.jpg` | тот же город и час, 1920×1080 — картинки бота | `SIZE=960x540 QUALITY=high VIEWS=game SOLAR=0.49 EXTRA="elev=26&dist=430&fov=34&at=0,10,-10&haze=1.7" npm run city:shots` |

Снимок стенд кладёт в `.city-shots/`; в исходник он переложен JPEG с качеством 90 (PNG весил бы
мегабайты, а дальше кадр всё равно жмётся в WebP). В облачном контейнере кадр рисует программная
отрисовка (SwiftShader) — те же шейдеры, что на видеокарте, только медленнее.

`npm run splash:build` режет из `city-full.jpg` заставку 900×1500 (`public/assets/splash/boot.webp`,
качество 36, **53.6 КБ** по выводу скрипта) и её предпросмотр в 12 точек строкой в `index.html`
(167 знаков), из `assets-src/brand/crest.svg` — значки, из `city-wide.jpg` и герба — картинки бота
(`docs/bot-assets/`).

### Почему этот кадр

Сняты четыре варианта — `docs/visual-shots/55…58`:

* **55, закат (выбран).** Ворота с двумя стягами внизу, площадь с рынком, собор, донжон, река и лес
  наверху. Солнце низко (`solar` 0.49 — последние минуты перед закатом, золото рига в полную силу),
  тени длинные, черепица горит. Наверху — тёмный лес: на нём читается название без плашки; внизу —
  тёмные крыши: на них полоса и присказка.
* **56, рассвет** (`solar` 0.02) — тот же город, свет площе: на телефоне от заката почти не отличить,
  а тепла меньше.
* **57, зима** (`SEASON=winter`) — красиво, но светлый снег под светлыми строками требует плотного
  затемнения, и половину года заставка спорила бы с летним городом за ней.
* **58, осада у стен** (`SIZE=540x900 QUALITY=high SHOTS=wall-outside EXTRA="hour=21" npm run tw:shots`)
  — ролик боя у стены: войско со стягами, лестницы, золото есть, но полкадра — пустое поле, а город —
  полоса домов вдали. Это кадр боя, а не лицо игры.

**Дымка `haze=1.7`.** Ракурс заставки ниже ракурса игры (30° против 52°), и туман стенда, рассчитанный
на камеру игры, топил дальний лес и реку в молоке — кадр выходил серым. `haze` отодвигает туман только
у стенда; по умолчанию 1, кадр игры прежний.

### Кадрирование

Кадр вертикальный (0.6) и лежит `object-fit: cover`. Телефон (0.46) режет его по бокам и оставляет
77 % ширины — город целиком по высоте. Широкое окно (16:10) видит 37 % высоты, и `object-position:
50% 31%` в `index.html` ставит это окно на донжон, собор и площадь. Числа записаны там, рядом с CSS:
подрезает браузер, а не скрипт. Те же числа — у стартового экрана (`.start-art`) и у предпросмотра
(`#boot-blur`); это держит тест (`src/boot/boot.test.ts`).

Отдельным файлом, а не строкой внутри `index.html`: вложенная целиком, картинка отодвигает первый кадр
экрана загрузки на 3G на полсекунды и появляется в тот же момент (docs/loading.md). Строкой лежит только
предпросмотр — полкилобайта.

## Арт перехода — убран

Занавес первого входа на карту («дружина перед чужой крепостью», `march-full.png`) ушёл из игры вместе
с артом и своей ступенью в `npm run splash:build`: при пороге показа в 240 мс и первом входе на карту в
десятки миллисекунд он не показывался практически никогда (docs/SUBTRACT.md). Исходник остался в
истории git, как и «вождь у костра».
