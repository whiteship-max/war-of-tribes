# TRIBE

Telegram Mini App: low-poly 3D-стратегия о развитии племени. Концепция: docs/concept.md.

Интерфейс диегетический: данные живут внутри зданий. Тап по постройке в сцене открывает её панель —
ресурсы на складе, дерево технологий в хранилище знаний, вольный сбор у костра. Внизу три раздела без
места: «Племя», «Здания», «Задания». «Здания» — основной путь к любой постройке: сначала уже построенные
(тап открывает панель), потом то, что можно поставить (тап начинает стройку).

Каждый тип здания строится ровно один раз, дальше растёт уровнями — их десять. Уровень даёт рабочее
место, +10% выработки и прибавку к своему пассивному эффекту, а на 4-м и 8-м здание меняет модель
на более крупную. Материалы моделей берутся от эпохи, поэтому переход эпохи заметно перестраивает деревню.

Первая партия ведётся за руку: строка поверх сцены и подсветка цели — от «тапни костёр» до склада,
где лежат все запасы. Каждый шаг закрывается настоящим действием, «Пропустить» доступно с первого экрана.

Соседи живут на общей карте: сетка 200×200 с координатами вида 541|822, ИИ-поселения с племенами и
варварские лагеря. Карта открывается кнопкой в верхнем правом углу — перетаскивание, щипковый зум,
тап по клетке открывает карточку с расстоянием, временем пути и разведданными. Оттуда уходят походы:
атака, разведка, поддержка. Пока армия в пути, деревня стоит без защиты — это видно перед отправкой.
Мира на сервере пока нет: он генерируется по сиду на клиенте за интерфейсом `worldApi` (см. CLAUDE.md).

## Запуск

    npm install
    npm run dev

Открыть http://localhost:5173. Вне Telegram игра работает в браузере, сохранение в localStorage.

## Сборка

    npm run build

Папка dist/ — статический сайт, его можно выложить на любой хостинг (GitHub Pages, Vercel, Cloudflare Pages)
и указать URL в BotFather как Web App.
