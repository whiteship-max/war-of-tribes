# TRIBE

Telegram Mini App: low-poly 3D-стратегия о племени позднего средневековья. Концепция: docs/concept.md.

Партия начинается с готовым посёлком за стеной: все здания стоят с первой секунды, эпох, технологий
и стройки с нуля нет. Игра — про дружину, карту и бой: сковать снаряжение в кузнице, нанять отряд в
казармах, разведать соседа, сходить в поход, взять замок с казной.

Интерфейс диегетический: данные живут внутри зданий. Тап по постройке в сцене открывает её панель —
ресурсы на складе, ковка в кузнице, наём в казармах, указы и казна в Доме вождя, закупка на рынке,
вольный сбор у костра. Внизу три раздела без места: «Племя», «Здания», «Задания». «Здания» — основной
путь к любой постройке: список посёлка, тап открывает панель.

Каждого типа здания в посёлке ровно одно, и растёт оно уровнями — их десять. Уровень даёт рабочее
место, +10% выработки и прибавку к своему пассивному эффекту, а на 4-м и 8-м здание меняет модель
на более крупную. Стиль один — позднее средневековье: штукатурка, черепица, фахверк, каменная стена.

Первая партия ведётся за руку: строка поверх сцены и подсветка цели — от кузницы и первого копья до
казарм, карты и разведки соседа. Каждый шаг закрывается настоящим действием, «Пропустить» доступно
с первого экрана.

Соседи живут на общей карте: сетка 200×200 с координатами вида 541|822, ИИ-поселения с племенами,
варварские лагеря и замки. Карта открывается кнопкой в верхнем правом углу — перетаскивание, щипковый
зум, тап по клетке открывает карточку с расстоянием, временем пути и разведданными. Оттуда уходят
походы: атака, разведка, поддержка. Пока армия в пути, деревня стоит без защиты — это видно перед
отправкой. Мира на сервере пока нет: он генерируется по сиду на клиенте за интерфейсом `worldApi`
(см. CLAUDE.md).

## Запуск

    npm install
    npm run dev

Открыть http://localhost:5173. Вне Telegram игра работает в браузере, сохранение в localStorage.

## Сборка

    npm run build

Папка dist/ — статический сайт, его можно выложить на любой хостинг (GitHub Pages, Vercel, Cloudflare Pages)
и указать URL в BotFather как Web App.
